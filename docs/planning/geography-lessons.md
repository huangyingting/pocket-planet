# 地理课堂：和初中地理结合的动画课

> 规划日期：2026-10-21  
> 目标：把寰星已有的地球、模型、天象剧场变成一套**能动起来的初中地理课**。每个知识点都配一段动画：在真实的三维地球上画线、着色、让太阳和季节转动，并调用已有的 3D 模型作为例子。

## 1. 设计原则

1. **动画讲原理，模型举例子。** 原理用叠加在地球上的动画演示：经纬线一条条画出来，晨昏线扫过地球，太阳直射点在回归线之间来回移动，板块边界亮起来，季风风向随季节翻转。例子用已有的 536 个模型，比如格林尼治天文台、珠穆朗玛峰、北极熊和帝企鹅、富士山、袋鼠。
2. **对齐课本，但不照抄。** 按人教版初中地理（七上、七下、八上、八下）的章节组织，每课标注对应章节和知识点。文字面向 12–14 岁学生，中英双语。
3. **示意要说清楚。** 季风箭头、气温带、地势阶梯分界线都是简化示意，界面上会注明“示意”，和天象剧场的做法一致。
4. **能停、能拖、能自己探索。** 每一步都可以暂停，可以拖时间滑块（一天中的时刻、一年中的月份），也可以随时退出、自由转动地球。
5. **课后小测。** 每课 3 道题，包括选择题和“在地球上点出来”的定位题。完成情况保存在本地。
6. **不增加首屏负担。** 课程模块按需加载（lazy chunk），叠加层用一张低分辨率画布贴图加少量线条，手机上也能流畅运行。

## 3. 怎么扩展（技术方案）

### 3.1 地球场景新增的接口（`src/client/globe/scene.ts`）

- `simTime`：设置后太阳位置按这个时刻计算（默认是真实时间），用来加速自转和公转。
- `forceDayNight`：课上强制显示晨昏线，不受“昼夜”开关影响。
- `onFrame` 钩子：叠加层每帧更新，课程动画运行期间持续渲染。
- `forceShow`：课上要讲的模型不受缩放等级限制，始终显示。
- `countryShapes()`：读取国家多边形和所属大洲，用来给大洲着色。

### 3.2 课程舞台（`src/client/lessons/stage.ts`）

在地球上叠加一层“课堂黑板”：

- **画布贴图层**：一张等距圆柱投影的画布贴在略大于地球的球面上，用来画色带（五带、半球、气温带、大洲、大洋、阶梯）。画布只在内容变化时重画。
- **线条层**：纬线、经线、折线（河流、分界线、航线），支持“逐渐画出”的动画。
- **流动箭头**：沿路径移动的小箭头，表示风向、板块运动、河流流向、自转方向。
- **标记和标签**：脉动的点和跟随地球转动的文字标签（城市、太阳直射点、大洋名）。
- **时间控制**：一天中的时刻、一年中的日期，驱动太阳直射点和晨昏线。

### 3.3 课程数据（`src/client/lessons/data.ts`、`geo.ts`）

每课是一组步骤。每一步包括双语标题和正文、镜头位置、要显示的叠加内容、要突出的模型，以及可选的时间动画。分界线、河流等折线放在 `geo.ts`，都是根据公开地图简化描出的示意线。

### 3.4 播放器（`src/client/lessons/player.ts`）

- 菜单新增“地理课堂”磁贴，课程列表按年级分组，显示完成状态。
- 课卡：步骤点、上一步/下一步、播放/暂停、时间滑块、“示意”标签。
- 课后小测：选择题即时反馈；定位题在地球上点一下，显示误差距离。
- 路由 `#lesson/<id>`，课堂模式下可以复制直达链接。

## 4. 验收标准

- 16 课全部可以从菜单进入，中英文都完整；每课至少 4 个动画步骤和 3 道小测题。
- 单元测试：课程数据完整性（引用的模型都存在、双语齐全、答案合法、坐标合法），太阳直射点纬度计算（夏至约 23.4°N，冬至约 23.4°S）。
- 端到端测试：打开课程列表，播放一课，叠加层出现，完成小测并记录进度；`#lesson/<id>` 链接能直达。
- 手机性能：课程模块不进入首屏包；4 倍降速模拟下，课程动画帧时间不比普通浏览差太多。
- 每课截图人工检查一遍。

### 6.2 引擎扩展

- **课程元数据**（`kit.ts`）：每课有 `strand`（主题）、`grade?`（人教版册次，没有则不在中国课程里）、`tracks`（国际课程）、`keys`（本课要点）。
- **气候与自然带地图**（`climate.ts`、`stage.ts`）：按纬度带和大洲规则逐像素分类，再按到东西海岸的距离区分大陆东西岸和内陆。`{k:'climate'}` / `{k:'biome'}` 填色，可以用 `only` 只显示一种类型。地图是示意的，课程里标“示意”。
- **课卡图表**（`figs.ts`）：步骤和小测题都可以带一张 SVG 图，包括气候图（16 个城市的月均温和降水，可并排比较，也可以隐藏城市名做判读题）、折线图、条形图、饼图、人口金字塔、图例，以及 11 张示意图（水循环、等高线、岩石循环、河流、海岸、温室效应、比例尺、指向标、天气符号、地球圈层、河谷与冰川谷）。图表带进场动画，尊重“减少动态效果”设置。数据是约数，图题注明。
- **镜头自动取景**（`stage.ts` 的 `fitView`）：每一步把要画的内容（国家轮廓、线、标注、物体）收进课卡旁的空白区，地球中心移到这块区域，镜头正上方俯视，不再倾斜。区域越小，镜头越低，但最低到 0.8 个地球半径，保留周边参照。全球性的内容（纬度带、气候图、绕地球一圈的纬线）保持整球视角；需要整球的步骤可设 `wide: true`。
- **播放器**：课程列表顶部是课程体系下拉框（记住选择，中文默认人教版，英文默认全部主题）；人教版按册分组，其他按主题分组，每组显示完成进度。课后显示“本课要点”和“下一课”。

### 6.3 测试

- 单元测试：每课有主题、至少一个课程体系和要点；每个课程体系的“下一课”能走完整个课程；图表引用的城市、金字塔、示意图都存在且能渲染；气候分类对 13 个典型城市给出教材里的类型。
- 端到端测试：切换课程体系后分组和课程正确，课后要点和“下一课”出现，气候课的图表能显示。
